# FOLLICLE — Deployable Website

This is a static HTML website. The website content, CSS, and JavaScript are included in `index.html`.

## Preview locally
1. Extract this folder if it came as a ZIP.
2. Open `index.html` in your browser.

## Deploy to Vercel
Option A — quickest:
1. Go to https://vercel.com/new
2. Import a Git repository containing this folder, or use Vercel CLI from this folder.
3. No build command is required for this static HTML site.

Option B — GitHub:
1. Create a new GitHub repository.
2. Upload `index.html` and this README.
3. Import the repository in Vercel and deploy.

## Deploy to Netlify
1. Open https://app.netlify.com/drop
2. Drag and drop the extracted `FOLLICLE_Deployable` folder (or a ZIP containing the site files).
3. Netlify will publish it as a static site.

## Notes
- The site uses Google Fonts and GSAP from CDNs, so an internet connection is needed for those external assets.
- The contact form is a frontend demo only; it does not send submissions or book appointments.
- Clinic profiles and patient results are demo placeholders.
